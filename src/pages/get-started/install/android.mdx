# Установка NetBird на Android

Приложение Android поддерживает смартфоны, планшеты и устройства [Android TV](android-tv) под управлением Android 8.0 и новее. 

## Где скачать

У NetBird есть официальное приложение для Android, которое можно скачать в Google Play Store:

<p>
    <a href="https://play.google.com/store/apps/details?id=io.netbird.client" target="_blank">
        <img src="/docs-static/img/get-started/android/google-play-badge.png" alt="playstore" className="imagewrapper-medium"/>
    </a>

</p>

APK-версии также доступны для прямой установки на Android через [репозиторий NetBird Android на GitHub](https://github.com/netbirdio/android-client/releases).

## Настройка NetBird на Android

### Первый запуск 

При первом запуске NetBird сообщит, что используется сервер управления по умолчанию. 

<img src="/docs-static/img/get-started/android/first-install-dialog.png" alt="firstinstall" className="imagewrapper-medium"/>

Нажмите «Continue», чтобы подтвердить это. После этого откроется главный экран приложения. 

<img src="/docs-static/img/get-started/android/main-screen.png" alt="mainscreen" className="imagewrapper-medium"/>

### Настройка сервера управления

<Note>
    Этот шаг относится только к пользователям self-hosted или облачным пользователям, регистрирующим устройство с помощью setup key. Если вы используете облачный NetBird и _не_ регистрируете устройство с помощью setup key, этот шаг можно пропустить и перейти к разделу [Подключение к вашей сети](#connecting-to-your-network)
</Note>

Откройте меню-гамбургер в левом верхнем углу главного экрана и перейдите в меню «Change Server».

<img src="/docs-static/img/get-started/android/change-server-menu-item.png" alt="changeserver" className="imagewrapper-medium"/>

При смене сервера текущая конфигурация NetBird на устройстве удаляется, поэтому перед продолжением потребуется подтвердить действие:

<img src="/docs-static/img/get-started/android/confirm-erase-config.png" alt="confirmeraseconfig" className="imagewrapper-medium"/>

Введите адрес сервера управления. Для облачных пользователей это `https://api.netbird.io:443`. Для self-hosted пользователей обычно используется `https://your_management_server_url:443`, но при необходимости можно проверить поле `exposedAddress` в `config.yaml` (или `management.json` в старых многоконтейнерных конфигурациях). 

Если устройство регистрируется с помощью setup key, выберите «+ Add this device with a setup key» и введите setup key. Нажмите «change», чтобы применить новую конфигурацию сервера управления. При успешном изменении появится следующий экран:

<img src="/docs-static/img/get-started/android/server-changed.png" alt="serverchanged" className="imagewrapper-medium"/>

Теперь можно подключиться к вашей сети NetBird!

#### Подключение к вашей сети

Нажмите кнопку с логотипом NetBird для подключения. Приложение запросит разрешение на создание VPN-подключения: 

<img src="/docs-static/img/get-started/android/vpn-connection-request.png" alt="vpnconnectionrequest" className="imagewrapper-medium"/>

Нажмите «OK». Если вы не вводили setup key в меню «Change Server», потребуется пройти аутентификацию у вашего SSO-провайдера. NetBird откроет окно браузера, где потребуется войти в учётную запись SSO-провайдера.

После входа NetBird подтвердит успешную аутентификацию. После закрытия окна браузера устройство должно подключиться.
