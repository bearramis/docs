# Установка на macOS

Клиент NetBird позволяет подключить узел к уже существующему развёртыванию NetBird. Если развёртывание NetBird ещё не создано, доступны управляемый вариант и [self-hosted](https://docs.netbird.io/selfhosted/selfhosted-quickstart) вариант с самостоятельным размещением.

## Установка одной командой

```bash
curl -fsSL https://pkgs.netbird.io/install.sh | sh
```

Эта команда устанавливает полноценное приложение NetBird, включая графический интерфейс и сервис демона.

### Установка пакета

1. Скачайте установщик последней версии macOS для вашего [процессора](https://support.apple.com/en-us/HT211814 ):
    - Intel: <Button href="https://pkgs.netbird.io/macos/amd64" variant="text" arrow="right">Скачать NetBird для Intel</Button>
    - M1 & M2: <Button href="https://pkgs.netbird.io/macos/arm64" variant="text" arrow="right">Скачать NetBird для Apple Silicon</Button><br />
_Если требуется более старая версия, смотрите [релизы] NetBird(https://github.com/netbirdio/netbird/releases/latest)_
2. Выполните шаги установки
3. Приложение NetBird будет установлено в `/Applications`, а также будет добавлен сервис демона
4. После установки выполните шаги из раздела [Запуск NetBird с входом через SSO](#Running-NetBird-with-SSO-Login) steps.

<Note>
    Чтобы удалить клиент, удалите приложение из `/Applications`
</Note>

### Установка через Homebrew

1. Скачайте и установите Homebrew с https://brew.sh/
2. If netbird was previously installed with homebrew, you will need to run:
```bash
# Остановите и удалите сервис демона:
sudo netbird service stop
sudo netbird service uninstall
# отключите приложение
brew unlink netbird
```

<Note>
    NetBird скопирует существующую конфигурацию из стандартных путей конфигурации NetBird в новое стандартное расположение
</Note>

3. Установите клиент
```bash
  # только CLI
  brew install netbirdio/tap/netbird
  # графический пакет
  brew install --cask netbirdio/tap/netbird-ui
```
4. Если установлен только CLI, необходимо установить и запустить сервис демона клиента:
 ```bash
  sudo netbird service install
  sudo netbird service start
```

### Установка только CLI (бинарный файл)

Если вам нужен только CLI-клиент без графического интерфейса — например, на серверах без GUI или для развёртывания через MDM/в парке устройств — можно напрямую установить отдельный бинарный файл.

#### Установка бинарного файла одной командой

<Warning>
    Бинарные архивы macOS из GitHub Releases **не подписаны Apple и не прошли нотариальную проверку**. Только официальный установщик `.pkg` с [pkgs.netbird.io](https://pkgs.netbird.io) содержит подписанные бинарные файлы. Неподписанный бинарный файл вызовет предупреждения Gatekeeper и может быть заблокирован политиками MDM. Для управляемого развёртывания парка устройств см. [Создание CLI-only .pkg для развёртывания через MDM](/manage/peers/mdm-deployment/macos-cli-pkg-deployment) which includes steps for signing the binary with your own Developer ID.
</Warning>

Скрипт установки поддерживает режим только бинарного файла: он скачивает архив, извлекает бинарный файл `netbird` в `/usr/local/bin/` и регистрирует демон launchd:

```bash
curl -fsSL https://pkgs.netbird.io/install.sh | USE_BIN_INSTALL=true SKIP_UI_APP=true sh
```

Чтобы обновить существующую бинарную установку, добавьте флаг `UPDATE_NETBIRD`:

```bash
curl -fsSL https://pkgs.netbird.io/install.sh | USE_BIN_INSTALL=true SKIP_UI_APP=true UPDATE_NETBIRD=true sh
```

#### Ручная установка бинарного файла

1. Откройте [релизы] NetBird(https://github.com/netbirdio/netbird/releases/latest)
2. Скачайте последнюю версию для macOS:
```bash
  # Для Apple Silicon (M1, M2, M3, M4):
  curl -L -o ./netbird.tar.gz https://github.com/netbirdio/netbird/releases/download/v<VERSION>/netbird_<VERSION>_darwin_arm64.tar.gz

  # Для Intel:
  curl -L -o ./netbird.tar.gz https://github.com/netbirdio/netbird/releases/download/v<VERSION>/netbird_<VERSION>_darwin_amd64.tar.gz

  # Универсальный бинарный файл (работает на обеих архитектурах):
  curl -L -o ./netbird.tar.gz https://github.com/netbirdio/netbird/releases/download/v<VERSION>/netbird_<VERSION>_darwin_all.tar.gz
```

<Note>
    Замените **VERSION** на номер последней выпущенной версии (e.g., `0.36.5`). Номера версий можно найти на [странице релизов](https://github.com/netbirdio/netbird/releases/latest).
</Note>

3. Распакуйте и установите бинарный файл:
```bash
  tar xzf ./netbird.tar.gz
  sudo mv netbird /usr/local/bin/netbird
  sudo chown root:wheel /usr/local/bin/netbird
  sudo chmod +x /usr/local/bin/netbird
```
4. Установите и запустите сервис демона:
```bash
  sudo netbird service install
  sudo netbird service start
```

Это создаёт демон launchd в `/Library/LaunchDaemons/netbird.plist`, который запускается от root (это требуется для управления сетевым интерфейсом WireGuard).

<Warning>
    Автоматические обновления через панель NetBird **не работают** для установок только из бинарного файла. Автообновление требует официальный установщик `.pkg` (it checks for the `io.netbird.client` package receipt). Для бинарных установок обновляйте клиент вручную или распространяйте обновления через вашу MDM-систему. See [Building a CLI-Only .pkg for MDM Deployment](/manage/peers/mdm-deployment/macos-cli-pkg-deployment) for a managed approach.
</Warning>

## Running NetBird with SSO Login
### Desktop UI Application
Launch the desktop app and click **Connect** in the main window or menu-bar menu. On first launch, choose NetBird Cloud or enter the URL of your self-hosted deployment. NetBird opens your browser to authenticate the device. See the [desktop app guide](/client/desktop-app) for the complete interface.

### CLI
Alternatively, you could use command line. Simply run
   ```bash
  netbird up
   ```

<Note>
    It will open your browser and prompt you for your email and password. Follow the instructions.
</Note>

Check connection status:
```bash
  netbird status
```

### Running NetBird with a Setup Key
In case you are activating a server peer, you can use a [setup key](/manage/peers/register-machines-using-setup-keys) as described in the steps below.

> This is especially helpful when you are running multiple server instances with infrastructure-as-code tools like ansible and terraform.

For unattended deployments across many machines, pre-populate the client config so each peer registers on first start. See [Bootstrap peers via config file](/manage/peers/bootstrap-via-config-file).

1. Login to the Management Service. You need to have a `setup key` in hand (see [setup keys](/manage/peers/register-machines-using-setup-keys)).

```bash
  netbird up --setup-key <SETUP KEY>
```

Alternatively, if you are hosting your own Management Service provide `--management-url` property pointing to your Management Service:
```bash
  netbird up --setup-key <SETUP KEY> --management-url http://localhost:33073
```

<Note>
    You could also omit the `--setup-key` property. In this case, the tool will prompt for the key.
</Note>

2. Check connection status:
```bash
  netbird status
```

3. Check your IP:

````bash
  sudo ifconfig utun100
````
